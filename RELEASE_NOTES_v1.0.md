# 自然入眠 v1.0.0

## English

This is the first public release of Nature Sleep for Android 8.0 or later on phones and tablets. APK: `nature-sleep-v1.0.apk`.

### Included

- Seven soundscapes with matching video backgrounds: rainforest, waves, stream, night insects, campfire, sleep music, and brainwave sleep.
- Sleep timer, media notification controls, headset next/previous, minimal mode, and motion settings.
- Android package: `com.rainsleep.app`; versionCode: `1`; versionName: `1.0.0`.
- The APK is signed with the project author's local signing key. The key and password are not included in the Release.

### Installation

Download and install `nature-sleep-v1.0.apk`. This is a fresh-install package. Android may ask you to allow installation from the source you used.

This is a personal experimental project. No long-term maintenance, bug-free operation, or compatibility with every device is promised. Audio experiences vary; the app does not promise to improve sleep and is not a substitute for medical advice or treatment.
