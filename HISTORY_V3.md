# Historical Version 3 Notes

English | [简体中文](#简体中文)

This file preserves selected interface and media notes from an earlier development stage. It is historical documentation only and is not the current release guide, APK download page, or current media inventory. For the current `v1.0.0` release, see [`README.md`](README.md), [`README.zh-CN.md`](README.zh-CN.md), and the current license/provenance records.

Earlier notes described the seven-scene list, individual video backgrounds, 3840 × 2160 rainforest footage, crossfades, system media-volume controls, and the Lucide Leaf icon. Some older statements about media sources and permissions were superseded. Current media and license status is recorded in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) and [`THIRD_PARTY_NOTICES.zh-CN.md`](THIRD_PARTY_NOTICES.zh-CN.md).
