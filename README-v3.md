# 自然入眠 3.0

安装包：dist/nature-sleep-v21.apk。与旧版使用同一应用标识和签名，可直接覆盖安装。
电脑预览：双击 D:\codex\rain-sleep\打开雨林预览.cmd。

此文件记录 v3/v20 历史安装包，不代表当前网页预览的素材清单。当前网页音景为：热带雨林、海浪、溪流、夜间虫鸣、篝火、助眠音乐、脑波助眠。
每种音景配独立视频。雨林为 3840×2160 长视频，其他视频以原始可用清晰度播放并进行首尾交叠。
应用内不再提供音量滑块；手机媒体音量键负责调节，定时结束前 30 秒渐弱。
左上角、桌面和通知图标采用 Lucide Leaf 线条形状。leaf-icon.png 是透明底导出图。
安卓适配图标使用透明底层，部分手机启动器仍可能添加系统底板。
夜间虫鸣画面由森林素材降低亮度处理，并非夜间实拍。

本文件原有的素材编号及“视频条目均为 Mixkit Stock Video Free License”结论已经过时，不应用作当前授权依据。当前网页 7 组音视频、文件哈希、来源核查状态和发布前缺口统一见 `ASSET_LICENSE_AUDIT.md` 与 `MEDIA_PROVENANCE_CURRENT.md`。目前不能确认所有视频都可随应用公开再分发。
- 叶子形状来自 Lucide，ISC License，使用随项目已有的 Lucide 库。

构建工具、素材与输出均在 D 盘。Android 8.0 及以上，支持手机和平板。
APK 编译和签名校验、浏览器布局/音景切换/定时功能已验证。尚无安卓真机测试。
