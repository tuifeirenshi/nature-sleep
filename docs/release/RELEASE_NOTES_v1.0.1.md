# Nature Sleep v1.0.1

For Android 8.0 or later on phones and tablets. Download `nature-sleep-v1.0.1.apk` to install. Updating an existing installation depends on the signing key and installed version code.

- Adds ten interface languages and updates the settings page, sound wheel, timer, and playback control interactions.
- Improves background video switching, audio preloading, and Android media controls; the app does not request notification permission.
- APK videos remain 4K, using H.264 at a target average of 9 Mbps; the campfire uses 30 fps. Original web media is unchanged.
- Android version name `1.0.1`, version code `10002`. Lock-screen controls and liquid glass can vary by device and still require device testing.

See the [license record](../licensing/PROJECT_LICENSES.md) and [media catalog](../media/MEDIA_CATALOG.md) for third-party media and unresolved permission questions. The app does not promise to improve sleep and is not a substitute for medical advice or treatment.
