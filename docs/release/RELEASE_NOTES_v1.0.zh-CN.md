# 自然入眠 v1.0.0

[English](RELEASE_NOTES_v1.0.md) | 简体中文

这是自然入眠的首次公开安装版本，适用于 Android 8.0 及以上手机和平板。APK 文件：`nature-sleep-v1.0.apk`。

## 包含内容

- 七种声音与对应视频背景：热带雨林、海浪、溪流、夜间虫鸣、篝火、助眠音乐、脑波助眠。
- 睡眠定时、媒体通知控制、耳机上一首/下一首、极简模式和动效设置。
- Android 包名：`com.rainsleep.app`；versionCode：`1`；versionName：`1.0.0`。
- APK 使用项目作者本机签名密钥签名。签名密钥和密码不随 Release 提供。

## 安装

下载并安装 `nature-sleep-v1.0.apk`。该版本为全新安装包。Android 可能要求你确认允许从当前来源安装应用。

## 素材与限制

音频、视频和图标来源及 SHA-256 见[项目许可证记录](../licensing/PROJECT_LICENSES.zh-CN.md)和[素材目录](../media/MEDIA_CATALOG.zh-CN.md)。Freesound 音频条目记录为 CC0；部分 Mixkit/Pexels 视频的许可条款对本项目公开仓库和 APK 分发方式仍待进一步确认。该状态已在说明中披露，但披露不代表取得许可。若权利人或平台提出要求，项目作者将评估并处理对应素材。
