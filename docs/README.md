Current app files live in `web/` and `android/`. Current build/preview scripts live in `scripts/`; see the [tool index](../tools/README.md) for supported checks and archived experiments. Release tags preserve their original source snapshots; later documentation fixes on `main` do not alter old tags or APKs.

English and Chinese documents use reciprocal links at the top. Documents containing both languages put English first and link to each section at the top. Keep both languages synchronized when changing current instructions.
